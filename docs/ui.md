# 🖥️ 画面

ブラウザーで `http://{PC}:5180/` を開く。StorageExplore と同じ軽い作り(自前の CSS と Bootstrap Icons)。

## 📄 ページ

| ページ | パス | 内容 |
|:--|:--|:--|
| 📷 カメラ一覧 | `/` | カメラごとに最新の保存画像、状態、最後の保存時刻、エラー。10 秒ごとに更新 |
| 🎥 カメラ | `/cameras/{id}` | ライブ(MJPEG)と静止画の切り替え |
| 🗂️ 保存画像 | `/cameras/{id}/images/{yyyyMMdd}` | 日付 → 時間 → サムネイル → 拡大 |
| 📊 状態 | `/status` | カメラごとの開閉、撮影の fps、MJPEG と H.264 の fps・ビットレート・クライアント数、H.264 のエンコーダー、最後の保存、エラー、保存先の空き容量。1 秒ごとに更新 |

- カメラ一覧ではライブを開かない(HTTP/1.1 は 1 つのサーバーに同時 6 接続まで。HTTPS なら HTTP/2 で制限がない)

## 🎥 カメラ

- **ライブ:** localhost か HTTPS で WebCodecs が使えるブラウザーでは H.264、ほかは MJPEG。映像の右上に今の方式を出す。H.264 をデコードできないときも MJPEG に切り替える
- **接続を切る:** ページを離れる、または静止画に切り替えると接続を切る(H.264 は WebSocket を閉じ、MJPEG は画像の `src` を外す)
- **静止画:** 更新ボタンと自動更新(5 / 10 / 30 / 60 秒)。閉じているカメラは開いてから撮るので、最初の 1 枚は約 2 秒かかる

## 🗂️ 保存画像

- **日付:** 新しい順に選ぶ
- **時間:** 0〜23 時の枚数。画像のない時間は選べない。最初は最新の画像の時間
- **サムネイル:** 選んだ時間の分だけ並べ、見える分から読み込む(ブラウザーは画面の少し先まで読み込む)
- **更新ボタン:** 開いてから保存された画像を読み直す
- **拡大:** サムネイルを押すと開く。その日の全部の画像を順にたどれる

| キー / ボタン | 動き |
|:--|:--|
| ← / → | 前 / 次 |
| Home / End | 最初 / 最後 |
| Space | タイムラプスの再生 / 停止(5 / 10 / 20 / 30 fps。最後まで行ったら止まる) |
| Esc | 閉じる |
| ⬇ | ダウンロード(`{id}_{yyyyMMdd}_{HHmmss}.jpg`) |

- **タイムラプス:** 「Time-lapse」ボタンは選んだ時間の最初から再生する
- **先読み:** 次の 3 枚を先に読み込む

## ✅ 確認

組み込みブラウザーで、実際のカメラを 5 秒ごとに保存しながら確かめた(画像は CSS で隠して、配置と値だけを見た)。

- **カメラ一覧:** 最新のサムネイル(320x240)、状態、時刻、リンク
- **カメラ:** ライブ 640x480。ページを離れると、サーバーのクライアント数が 0 に戻る。静止画は切り替え・更新・5 秒ごとの自動更新で読み直す
- **保存画像:** 日付の切り替えで URL が変わる。時間ごとの枚数、サムネイル
- **拡大:** ←/→/Home/End、Space で再生(最後で止まる)、Esc で閉じる、先読み、ダウンロード名
- **そのほか:** 存在しないカメラと画像のない日付の表示、状態のページ。コンソールのエラーはない

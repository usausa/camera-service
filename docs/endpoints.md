# 🔗 エンドポイント

## 📋 一覧

| パス | 内容 |
|:--|:--|
| `/cameras/{id}/stream.mjpg` | MJPEG([📡 配信](streaming.md)) |
| `/cameras/{id}/snapshot.jpg` | 静止画。カメラが閉じていれば開いて 1 枚 |
| `/api/images/{id}` | 保存画像のある日付(`yyyyMMdd`、新しい順) |
| `/api/images/{id}/{yyyyMMdd}` | その日の時刻(`HHmmss`、古い順) |
| `/images/{id}/{yyyyMMdd}/{HHmmss}.jpg` | 保存画像 |
| `/images/{id}/{yyyyMMdd}/{HHmmss}/thumbnail.jpg` | 保存画像のサムネイル |
| `/api/devices` | PC のカメラと形式 |
| `/health` | ヘルスチェック |

- 設定にない `id`、8 桁の正しい日付でないもの、6 桁の正しい時刻でないもの、ない画像は 404(ほかのパスを読む方法はない)

## 🖼️ 保存画像とサムネイル

- **キャッシュ:** `Cache-Control: private, max-age=86400` と `ETag`(更新時刻と大きさから作る)。同じ `ETag` の要求には 304 を返す
- **サムネイルの作り方:** WIC の JPEG デコーダーで縮小しながら YCbCr の面にデコードし、そのまま JPEG にする(色の変換はしない)
  - 幅 320 を目安に、デコーダーが選べる大きさ(1/2、1/4、1/8)になる。縮小した色差は輝度と同じ大きさで出てくるので、2x2 を平均して 4:2:0 にする
  - 品質 80。サーバーのメモリーに合計 64 MB まで置く(よく使わないものから消す)

| 元の画像 | サムネイル |
|:--|:--|
| 640x480 | 320x240(約 17 KB) |
| 1280x720 | 320x180 |
| 1920x1080 | 480x270(1/4。デコーダーが選ぶ) |

- 作る時間: 1 枚約 2〜4 ms(640x480、HTTP を含む)。メモリーにあれば約 2 ms

## ❤️ ヘルスチェック

| 結果 | HTTP | 条件 |
|:--|:--|:--|
| `Healthy` | 200 | 下のどれでもない |
| `Degraded` | 200 | 保存先のドライブの空き容量が `Retention:MinFreeSpace` より少ない |
| `Unhealthy` | 503 | カメラが失敗の状態(開けない、フレームが止まった)、保存の失敗、保存先に書けない(起動時に確かめ、保存できたら戻る) |

- カメラは使うときだけ開くので、誰も使っていないカメラは最後の状態のまま

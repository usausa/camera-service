# 📡 配信

## 🔗 エンドポイント

| パス | 内容 |
|:--|:--|
| `/` | カメラの一覧(仮の画面。Live でライブ、Snapshot で静止画) |
| `/cameras/{id}/stream.mjpg` | MJPEG(`img` で表示できる) |
| `/cameras/{id}/snapshot.jpg` | 静止画。カメラが閉じていれば開いて 1 枚 |
| `/api/devices` | PC のカメラと形式 |
| `/health` | ヘルスチェック |

- 設定にない `id` は 404

## 🔄 カメラを開く・閉じる

- 使う側(MJPEG のクライアント、静止画の要求)がカメラを借りる。最初の 1 人で開き、最後の 1 人が返してから `IdleTime` で閉じる
- 開いてから `WarmupTime` のフレームは使わない
- 失敗(開けない、エラー、`FrameTimeout` の間フレームが来ない)のときは閉じて開き直す。間隔は 5 → 10 → 30 → 60 秒。借りる人がいない間は開き直さない
- デバイスと形式は最初に開くときに探し、失敗のあとに探し直す
- 開く・閉じる・開き直すは 0.5 秒ごとのタイマーで 1 つずつ進める(最初の 1 人のときはすぐ)

## 🖼️ JPEG

- カメラのスレッドで、待っているクライアントがいるときだけ `Stream:Fps` に間引いてエンコード。1 回のエンコードを全クライアントで共有(最新の 1 枚だけを渡す)
- YUY2 や範囲の狭い NV12 は、フル範囲の NV12 にしてから WIC でエンコード
- 作業用のバッファに書いてから実際の大きさのフレームに写す。フレームごとに最大の大きさ(640x480 で約 0.9 MB)のバッファを持たない
- カメラを閉じると、エンコーダーとバッファも手放す
- MJPEG は各フレームの後にすぐ次の区切りを送る(ブラウザーは次の区切りが来てから表示する)
- 画面のライブは、画面を離れると画像の `src` を外して接続を切る(外さないとブラウザーが読み続けることがある)

## 📊 計測

ELECOM 2MP Webcam、YUY2 640x480 30fps、`Stream:Fps` 10、Release。

| 項目 | 値 |
|:--|:--|
| カメラを開く | 0.81〜0.83 秒(デバイスを探す約 0.7 秒を含む。閉じた直後に開き直したときは 0.09 秒) |
| 静止画(閉じているとき) | 1.8〜1.9 秒(開く + `WarmupTime` 1 秒) |
| 静止画(開いているとき) | 71 ms |
| MJPEG | 10 fps、1 枚約 64 KB |
| 閉じるまで | 最後のクライアントから約 10.7 秒(`IdleTime` 10 秒 + タイマー) |
| ライブを止めてから接続が切れるまで | 3〜7 ms |
| CPU(1 コア) | 誰も見ていないとき 0.57 %、MJPEG 1 台 3.6 % |

- 開いた直後の明るさ(フレームの平均): 最初から落ち着いた値に近く、0.3〜0.6 秒に最大 8 % ほど揺れる。`WarmupTime` の既定は 1 秒のまま
- サービス(LocalSystem、セッション 0)でも同じように動く
